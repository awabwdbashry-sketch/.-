# 🇬🇧 Movenpick Jeddah

## 📖 Project Overview

**Movenpick Jeddah** is a luxury hotel-inspired website designed to provide a modern and elegant hospitality experience.

The project focuses on a premium visual interface, responsive layouts, smooth interactions, and a clean user experience across different screen sizes. ✨

---

## ✨ Features

- 🏨 Luxury hotel-inspired design
- 📱 Fully responsive layout
- 🎨 Modern and elegant user interface
- 🧭 Easy-to-use navigation
- 🖼️ Hotel and service presentation sections
- ✨ Interactive visual effects
- 📜 Smooth scrolling
- 📱 Responsive mobile navigation
- ⚡ Lightweight and fast
- 🌐 Arabic-friendly interface
- 💻 Frontend-only project

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

---

## 📁 Project Structure

```text
Movenpick Jeddah/
│

└── script.js
```

## 🚀 How to Run

No backend, database, or additional dependencies are required.

Simply open:

```text
index.html
```

with any modern web browser such as:

- Google Chrome
- Microsoft Edge
- Firefox
